# Retail Sales Power BI Dashboard

## Project Overview

This dashboard was created in Power BI using a retail sales dataset to explore sales performance, profitability and customer purchasing patterns.

The report combines KPIs, trend analysis and interactive visualisations to help identify key business insights and highlight performance across categories, cities and shipping methods.

## Tools Used

* Power BI
* Power Query
* DAX
* Excel

## Dashboard Contents

* Sales Overview
* Profit Overview
* Category Performance
* Top Cities by Sales and Profit
* Shipping Mode Analysis
* Sales Trends Over Time
* Sales vs Profit Comparison

## Key Findings

* Technology was the strongest-performing category in terms of sales.
* A small number of cities generated a significant share of overall profit.
* Standard Class was the most commonly used shipping method.
* Sales generally increased over the reporting period, with some seasonal fluctuations.
